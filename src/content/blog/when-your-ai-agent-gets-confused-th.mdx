Model เก่งขึ้น Agent ทำงานได้มากขึ้น มันก็ดีสำหรับผมแหละครับ เดี๋ยวนี้ผมโยนงานที่ต้องแก้หลายไฟล์ให้มันทำได้ กลับมาก็มีทั้ง diff และเทสต์ให้ดู วันไหนไปได้สวย ผมใช้เวลากับการเตรียมงานน้อยลง แล้วมีเวลาไปคิดว่าเราอยากให้ product ทำอะไร ผมชอบทำงานแบบนี้นะ

ที่ผมคิดอยู่คือ พอเริ่มรู้สึกว่ามีอะไรแปลก ๆ เราจะทำยังไง Agent อธิบายโค้ดได้ เขียนเทสต์ให้ได้ แล้วก็บอกว่าเทสต์ผ่านหมด ถ้าผมยังเอะใจ ผมรู้ไหมว่าควรเปิดดูตรงไหน หรือสุดท้ายก็กลับไปถาม Agent ตัวเดิมว่ามั่นใจแค่ไหน?

## ยกเลิกเดือนนี้ นับจากวันไหน?

สมมติผมให้ Agent เพิ่มจำนวน subscription ที่ยกเลิกในแต่ละเดือนบน dashboard มันไปเจอวันที่ลูกค้ากด Cancel ก็เอาวันนั้นมานับแยกตามเดือนแล้วเขียนเทสต์ให้ query สั้นดี กราฟก็ดูโอเค

ทีนี้ลองดูข้อมูลลูกค้าคนหนึ่ง เขากด Cancel วันที่ 28 กันยายน แต่ยังใช้บริการได้ถึง 12 ตุลาคม แบบนี้ควรนับเข้ายอดของเดือนไหน? ถ้าทีมอยากรู้ว่าลูกค้าตัดสินใจเลิกใช้ตอนไหน กันยายนก็สมเหตุสมผล ถ้าทีมอยากรู้ว่าลูกค้าหมดสิทธิ์ใช้บริการตอนไหน ก็ตอบตุลาคม เขียนเทสต์ให้ผ่านได้ทั้งสองแบบครับ

![วิศวกรดูเส้นทางที่แยกออกเป็นสองทางบนจอ](/assets/images/blogs/when-your-ai-agent-gets-confused/trace.webp)

ถ้าโจทย์ของทีมคือวันที่ลูกค้าหมดสิทธิ์ กราฟที่นับจากวันกด Cancel ก็เอาลูกค้าคนนี้ไปไว้ผิดเดือน ผมให้ Agent รีวิว diff อีกรอบได้ แล้วอาจได้คำอธิบายละเอียดว่าทำไม query ตรงกับเทสต์ แต่สิ่งที่ช่วยให้ผมไปต่อได้คือรู้ก่อนว่าทีมจะเอาตัวเลขนี้ไปตอบคำถามอะไร พอรู้แล้ว ผมก็ยกเคสนี้ให้ Agent แล้วตรวจผลกับคำตอบที่ผมหาได้เอง

## ส่วนที่ผมยังต้องเข้าใจ

ผมไม่ต้องจำทุกตารางหรือเขียน query เองตั้งแต่ต้น ให้ Agent ช่วยไล่ว่าวันที่แต่ละตัวมาจากไหน หรือช่วยเช็กข้อมูลสักสองสามแถวก็ได้ สิ่งที่ผมอยากเข้าใจคือเราใช้เงื่อนไขอะไรนับ และเปลี่ยนเงื่อนไขแล้วคำตอบจะเปลี่ยนยังไง ถ้าเพื่อนในทีมถามว่าทำไมลูกค้าคนนี้ไปอยู่ในยอดเดือนตุลาคม ผมควรตอบได้ในประโยคเดียว

![วิศวกรตัดสินใจด้วยตัวเองที่โต๊ะทำงาน](/assets/images/blogs/when-your-ai-agent-gets-confused/decision.webp)

Model เก่งขึ้น ผมก็ดีใจที่ส่งงานให้ Agent ช่วยทำได้มากขึ้น **พอผมเลือกส่งงานที่ Agent ทำออกไป งานนั้นก็เป็นผลงานของผมครับ** ถ้าตัวเลขผิด คนในทีมจะมาถามผมว่าเกิดอะไรขึ้น ผมอยากเปิด dashboard กับเขา หยิบข้อมูลมาดูสักแถว แล้วไล่หาคำตอบด้วยกันได้
