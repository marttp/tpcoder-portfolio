Model เก่งขึ้น Agent ทำงานได้มากขึ้น มันก็ดีสำหรับผมแหละครับ เดี๋ยวนี้ผมโยนงานที่ต้องแก้หลายไฟล์ให้มันทำได้ กลับมาก็มีทั้ง diff และเทสต์ให้ดู วันไหนไปได้สวย ผมใช้เวลากับการเตรียมงานน้อยลง แล้วมีเวลาไปคิดว่าเราอยากให้ product ทำอะไร ผมชอบทำงานแบบนี้นะ

ที่ผมคิดอยู่คือ พอเริ่มรู้สึกว่ามีอะไรแปลก ๆ เราจะทำยังไง Agent อธิบายโค้ดได้ เขียนเทสต์ให้ได้ แล้วก็บอกว่าเทสต์ผ่านหมด ถ้าผมยังเอะใจ ผมรู้ไหมว่าควรเปิดดูตรงไหน หรือสุดท้ายก็กลับไปถาม Agent ตัวเดิมว่ามั่นใจแค่ไหน?

## ลูกค้าย้ายบ้าน แล้วรายการแรกควรแสดงที่อยู่ไหน?

ตอนทำงานที่ Coda ผมเจอ flow จ่ายเงินที่ผูก billing details ไว้กับบัญชีผู้ใช้ สมมติรายการแรกใช้ที่อยู่ A ไปแล้ว วันหนึ่งลูกค้าย้ายบ้านและใช้ที่อยู่ B กับรายการถัดไป พอกลับมาเปิดรายการแรก เขาควรเห็นที่อยู่ไหน?

ถ้าให้ลูกค้ากรอกที่อยู่เองทุกครั้ง แล้วใช้ข้อมูลที่กรอกกับรายการนั้นอย่างเดียว เราก็ไม่มีที่อยู่ที่เซฟไว้ให้แก้เพื่อใช้รอบหน้า พอเพิ่มให้ลูกค้าเซฟที่อยู่ไว้ใช้ครั้งถัดไป เราต้องดูข้อมูลสองอย่างครับ ที่อยู่ที่จะเอามากรอกให้รอบหน้า กับที่อยู่ที่แต่ละรายการใช้ตอนจ่าย

![วิศวกรดูเส้นทางที่แยกออกเป็นสองทางบนจอ](/assets/images/blogs/when-your-ai-agent-gets-confused/trace.webp)

Agent เสนอให้เพิ่ม PATCH ตามโครงสร้างเดิม คือแก้ billing details ที่บัญชีผู้ใช้ ถ้ามองจากโค้ดว่าเก็บข้อมูลไว้ตรงไหน วิธีนี้ก็ดูสมเหตุสมผล แต่ในมุมลูกค้า เขาย้ายบ้านและอยากใช้ที่อยู่ B ครั้งถัดไป พอรายการเก่ายังอ้างอิงข้อมูลจากบัญชีเดียวกัน มันก็อ่านได้ B ตามไปด้วย PATCH ทำงานตามที่เขียนไว้ครับ ผลคือทุกรายการที่อ่านจาก reference เดียวกันเห็นค่าที่เพิ่งแก้

## ส่วนที่ผมต้องตัดสินเอง

ผมแก้ flow ให้แต่ละ transaction เก็บ billing details ของตัวเองได้ เคสที่ผมอยากดูคือ ใช้บัญชีเดียวกันจ่ายด้วยที่อยู่ A แล้วจ่ายอีกรอบด้วยที่อยู่ B พอกลับมาเปิดดูทั้งสองรายการ รายการแรกควรยังเป็น A ส่วนรายการที่สองควรเป็น B ถ้าเทสต์เช็กแค่ว่า PATCH แล้วบัญชีมีค่า B เทสต์ก็ผ่านได้โดยที่เราไม่เห็นว่ารายการแรกโดนกระทบ

ตรงนี้แหละครับที่ผมอยากจับให้ได้เวลารีวิวข้อเสนอของ Agent มันดูจากโค้ดได้ว่าตอนนี้ระบบอ่านและเขียนที่อยู่ตรงไหน ส่วนผมต้องคิดว่าลูกค้าตั้งใจเปลี่ยนที่อยู่เพื่ออะไร แล้วการเปลี่ยนครั้งนี้ควรมีผลกับรายการที่เขาจ่ายไปแล้วหรือเปล่า

![วิศวกรตัดสินใจด้วยตัวเองที่โต๊ะทำงาน](/assets/images/blogs/when-your-ai-agent-gets-confused/decision.webp)

ผมยังให้ Agent ช่วยไล่ว่ามีตรงไหนอ้างอิงข้อมูลนี้อยู่บ้าง หรือให้ช่วยเขียนเทสต์ได้ **พอผมเลือกส่งงานที่ Agent ทำออกไป งานนั้นก็เป็นผลงานของผมครับ** ถ้าวันหนึ่งมีคนถามว่าทำไมรายการเก่าถึงแสดงที่อยู่ใหม่ ผมต้องไล่เองได้ว่าเกิดอะไรขึ้น แล้วตอบเขาได้
