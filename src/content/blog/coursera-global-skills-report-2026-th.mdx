ใน Coursera Global Skills Report 2026 ยอดลงเรียน **Critical Thinking โต 107% จากปีก่อน** ครับ ขณะเดียวกัน ยอดลงเรียน GenAI บน Coursera และ Udemy รวมกันขึ้นไปเกิน 45 ครั้งต่อนาที จาก 25 ครั้งต่อนาทีในปี 2025

ถ้าคุณใช้ AI ช่วยทำงานได้แล้ว ทักษะอะไรจะสำคัญขึ้นตอนให้ AI รับงานไปทำเองบางขั้น? ผมให้น้ำหนักกับความสามารถในการกำหนดว่า AI ทำอะไรได้บ้าง และดูให้ออกว่าผลที่ได้ใช้ต่อได้หรือเปล่าครับ [Coursera Global Skills Report 2026](https://www.coursera.org/skills-reports/global)

## What people are learning

บน Coursera ยอดลงเรียน **AI Security โต 665%** และ **Agentic Workflows โต 546%** ส่วน GenAI โต 132% ครับ แต่ละหัวข้อมีฐานยอดลงเรียนเดิมต่างกัน อัตราโตจึงบอกว่าความสนใจเพิ่มเร็วแค่ไหน ส่วน GenAI ยังเป็นหัวข้อ AI ที่คนให้ความสนใจมากที่สุดในรายงาน

![อัตราเติบโตของยอดลงเรียน AI Security 665%, Agentic Workflows 546%, GenAI 132%, Complex Problem-Solving 126%, Critical Thinking 107% และ Innovation 74%](/assets/images/blogs/coursera-global-skills-report-2026/skills-enrollment-growth.png)

กราฟจากข้อมูลหน้า 14 ของรายงาน เทียบยอดลงเรียนช่วงเมษายน 2025 ถึงมีนาคม 2026 กับ 12 เดือนก่อนหน้า [อ่านรายงานฉบับเต็ม](https://assets.ctfassets.net/2pudprfttvy6/3mZxZaJwIW5MA1ZkQHxnzH/9a273e6e888617e1ae22376338438daf/Global_Skills_Report_2026.pdf#page=14)

## When an agent can take action

สมมุติว่าคุณให้ Agent อ่านคำขอคืนเงิน เช็กประวัติรายการ แล้วเปิดเคสให้ทีมดูครับ พอ Agent เปิดเคสเองได้ คุณต้องตอบให้ได้ว่า Agent อ่านข้อมูลอะไรได้บ้าง ใครมีสิทธิ์อนุมัติคืนเงิน และถ้า API timeout แล้วต้อง retry ระบบจะเปิดเคสซ้ำหรือเปล่า คำถามสุดท้ายนี่คือเรื่อง idempotency ที่คนทำ backend คุ้นอยู่แล้วครับ

เรื่อง Critical Thinking ก็มาอยู่ในงานแบบเดียวกัน รายงานพบว่าคนที่เรียนเรื่องสร้างแอปด้วย LLM ลงเรียนทักษะอย่างการแก้ปัญหาซับซ้อนและการใช้วิจารณญาณควบคู่กัน ลองนึกถึงกรณีที่ AI เสนอให้บันทึกที่อยู่สำหรับออกบิลไว้ใช้ครั้งหน้า ถ้าลูกค้าย้ายบ้าน คุณจะเก็บที่อยู่ของรายการเก่าแยกจากที่อยู่ปัจจุบันยังไง? แค่คำถามนี้ก็เปลี่ยนได้ทั้ง data model และ Test ที่ทีมต้องเขียนครับ [คู่ทักษะในรายงาน](https://assets.ctfassets.net/2pudprfttvy6/3mZxZaJwIW5MA1ZkQHxnzH/9a273e6e888617e1ae22376338438daf/Global_Skills_Report_2026.pdf#page=19)

## Skills I expect to use in 2028–2029

ผมเผื่อไว้ 2–3 ปีครับ ปีแรกอาจพอให้เข้าใจหลักการ ส่วนการลองกับข้อมูลของทีม เจอเคสที่พลาด แล้วปรับให้คนอื่นใช้ต่อได้ต้องผ่านอีกหลายรอบ ถ้าทีมเริ่มให้ AI ทำงานหลายขั้นในระบบที่ใช้อยู่ ผมมองว่าสามทักษะนี้จะได้ใช้บ่อยขึ้น

1. **AI Evaluation** คุณต้องนิยามก่อนว่าผลลัพธ์แบบไหนผ่าน และความผิดพลาดแบบไหนต้องส่งให้คนตัดสินใจ เช่น เอาเคสที่ AI เคยสรุปคำขอคืนเงินผิดมาทำเป็นชุดทดสอบ แล้วรันซ้ำทุกครั้งที่เปลี่ยน model หรือแหล่งข้อมูล
2. **Workflow Engineering และ AI Security** พอ Agent เรียก API ได้เอง การกำหนดสิทธิ์ การดูย้อนหลังว่า Agent ทำอะไรไปบ้าง และการ retry โดยไม่ทำรายการซ้ำ จะกลายเป็นส่วนหนึ่งของงานดูแลระบบ หลักพวกนี้ใช้ต่อได้เวลาเปลี่ยน framework ครับ
3. **Domain Knowledge และการออกแบบงาน** คนที่เข้าใจเงื่อนไขธุรกิจจะเลือกได้ว่างานส่วนไหนให้ AI ช่วย ส่วนไหนใช้กฎตายตัว และส่วนไหนให้คนตัดสินใจ เช่น ให้ AI สรุปหลักฐานของคำขอคืนเงิน แล้วให้เจ้าหน้าที่อนุมัติตามเงื่อนไขของธุรกิจ

ถ้าถามว่าผมจะเอารายงานนี้ไปทำยังไงกับชีวิต ผมจะเริ่มจากงานที่รู้จักอยู่แล้วครับ อย่างงาน backend ผมมีโจทย์ให้ลองทั้งการให้ Agent เรียก API การกำหนดสิทธิ์ และการเขียน Test สำหรับเคสที่พลาด พอเจอปัญหาจากงานที่เรารู้จัก จะพอมองออกว่าควรใช้เวลาเรียนเรื่องไหนเพิ่ม
