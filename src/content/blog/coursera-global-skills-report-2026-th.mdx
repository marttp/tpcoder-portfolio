ผมอ่าน Coursera Global Skills Report 2026 แล้วนึกถึงเวลาจะลงคอร์สสักตัวครับ สมมุติว่าผมเริ่มเรียนวันนี้ กว่าจะเรียนจบ หาโอกาสลองกับงาน แล้วเจอปัญหามากพอที่จะใช้เองเป็น ตอนนั้นอาจผ่านไปสองสามปีแล้ว ถ้าอย่างนั้น ในรายงานปีนี้มีอะไรที่น่าจะยังได้ใช้ตอนนั้นบ้าง?

## What people are learning

บน Coursera กับ Udemy รวมกัน ปี 2025 มีคนกดลงเรียน GenAI ประมาณ 25 ครั้งต่อนาที พอมาถึงรายงานปีนี้ ตัวเลขขึ้นไปเกิน 45 ครั้งต่อนาทีแล้วครับ คนหนึ่งลงได้หลายคอร์สนะครับ ตัวเลขนี้นับยอดลงเรียน

![ยอดลงเรียน GenAI ต่อนาทีในสองปี](/assets/images/blogs/coursera-global-skills-report-2026/genai-enrollments-per-minute.png)

แล้วคนที่ขยับจากการใช้ AI ไปเรียนเรื่องอื่น เขาสนใจอะไรกัน? บน Coursera ยอดลงเรียน AI Security โต 665% ส่วน Agentic Workflows โต 546% เทียบกับปีก่อนครับ แต่ละวิชามีคนเรียนเดิมเยอะน้อยต่างกัน ส่วน GenAI ยังเป็นหัวข้อ AI ที่คนสนใจมากที่สุดในรายงาน

![อัตราเติบโตของยอดลงเรียนหกทักษะ](/assets/images/blogs/coursera-global-skills-report-2026/skills-enrollment-growth.png)

[![ตารางจัดกลุ่มทักษะ AI ที่คนสนใจเรียน จากรายงานหน้า 27](/assets/images/blogs/coursera-global-skills-report-2026/report-27.jpg)](/assets/images/blogs/coursera-global-skills-report-2026/report-27.jpg)

ดูตารางหน้า 27 แล้วจะเห็นว่าคนที่เรียนเรื่องใช้เครื่องมืออย่าง ChatGPT กับคนที่เรียนเรื่องสร้าง Agent กำลังฝึกคนละอย่างครับ ฝั่งหนึ่งอยากได้คำตอบไปใช้ อีกฝั่งต้องคิดต่อว่าพอ Agent ได้คำตอบแล้ว จะยอมให้ไปทำอะไรกับระบบของเราได้บ้าง

## Where judgment comes in

อีกตัวเลขที่ผมสนใจคือยอดลงเรียน Critical Thinking โต 107% ครับ พอลองดูว่าคนคนเดียวกันเรียนอะไรคู่กันบ้าง ก็เจอทั้งคนที่เรียนพื้นฐาน AI ควบคู่กับการใช้วิจารณญาณ และคนที่เรียน GenAI ควบคู่กับวิธีคุยให้คนที่เกี่ยวข้องเข้าใจไปทางเดียวกัน

[![แผนภาพคู่ทักษะ AI และทักษะมนุษย์ที่ผู้เรียนเลือกเรียนร่วมกัน จากรายงานหน้า 19](/assets/images/blogs/coursera-global-skills-report-2026/report-19.jpg)](/assets/images/blogs/coursera-global-skills-report-2026/report-19.jpg)

ในรูปหน้า 19 เส้นที่หนากว่าหมายถึงมีคนเรียนทักษะคู่นั้นมากกว่า ส่วนหน้า 23 ขยายให้เห็นว่าทักษะฝั่งคนมีอะไรบ้าง ตั้งแต่การตั้งคำถามกับหลักฐาน ไปจนถึงการตัดสินใจว่าใครควรรับผิดชอบผลที่ตามมา

[![ตารางทักษะมนุษย์และตัวอย่างการใช้งาน จากรายงานหน้า 23](/assets/images/blogs/coursera-global-skills-report-2026/report-23.jpg)](/assets/images/blogs/coursera-global-skills-report-2026/report-23.jpg)

ผมนึกถึงเรื่องที่อยู่บนบิลครับ สมมุติว่าลูกค้าซื้อของครั้งแรกใช้ที่อยู่ A พอย้ายบ้านก็เปลี่ยนเป็น B ถ้าคุณให้ AI ช่วยเขียน API แก้ที่อยู่ แล้วเขียน Test ว่าแก้สำเร็จ คุณอาจได้โค้ดที่ผ่านทุก Test ที่ขอไป ทีนี้ลองเปิดบิลใบแรกล่ะ ที่อยู่ควรเป็นอะไร? พอถามแบบนี้ เราถึงจะรู้ว่าต้องเก็บที่อยู่ของแต่ละรายการแยกไว้ด้วย ความยากอยู่ที่นึกให้ออกว่าลูกค้าจะกลับมาเปิดบิลเก่าเพื่ออะไรครับ

## Where Thailand stands

[![อันดับประเทศใน AI-Human Skills Synergy Index จากรายงานหน้า 12](/assets/images/blogs/coursera-global-skills-report-2026/report-12.jpg)](/assets/images/blogs/coursera-global-skills-report-2026/report-12.jpg)

ไทยอยู่อันดับ 24 จาก 98 ในดัชนี AI-Human Skills Synergy Index ครับ คะแนน 60% มาจากข้อมูลผู้เรียนบน Coursera อีก 40% มาจากความพร้อมด้าน AI ของภาครัฐที่ Oxford Insights ประเมินไว้ เวลาอ่านอันดับนี้ ผมเลยใช้ดูว่าไทยอยู่ช่วงไหนเมื่อเทียบกับประเทศอื่น ส่วนถ้าอยากรู้ว่าบริษัทไทยกำลังหาคนทำงานอะไร อันนั้นต้องกลับไปดูประกาศงานครับ

## What I’d learn for 2028–2029

ถ้าให้ผมเลือกว่าจะเริ่มเรียนอะไรตอนนี้ ไว้ใช้ในอีก 2–3 ปี ผมจะเลือกจากสามเรื่องนี้ครับ

- **AI Evaluation** สมมุติว่าทีมเปลี่ยน model แล้วอยากรู้ว่าสรุปคำขอคืนเงินได้ดีขึ้นไหม ผมอยากเอาเคสที่เคยสรุปผิดกลับมาลอง แล้วดูว่าข้อมูลไหนหายหรือมีอะไรถูกเติมเข้ามาเอง แบบนี้ทีมถึงจะตัดสินใจได้ว่าควรเปลี่ยนไหม
- **Workflow Engineering กับ AI Security** ถ้า Agent เปิดเคสคืนเงินแล้ว API timeout เราจะรู้ได้ยังไงว่าเคสเปิดไปแล้วหรือยัง? ผมมองว่าการทำให้ retry ได้โดยไม่เปิดเคสซ้ำ กับการกำหนดว่า Agent อ่านข้อมูลลูกค้าได้แค่ไหน เป็นพื้นฐาน backend ที่ยังได้ใช้แม้ทีมเปลี่ยนเครื่องมือครับ
- **Domain Knowledge** ในงานเดียวกัน ให้ AI ช่วยรวบรวมหลักฐานอาจลดเวลาของเจ้าหน้าที่ได้เยอะ ส่วนจะอนุมัติคืนเงินหรือเปล่า คนออกแบบต้องรู้ก่อนว่าธุรกิจใช้เงื่อนไขอะไร และใครมีอำนาจตัดสินใจ

สำหรับผม จุดเริ่มคืองานที่รู้จักดีพอจะจับได้ว่า AI พลาดอะไรครับ อย่างเรื่องบิล ผมรู้ว่าจะเปิดใบไหนกลับมาดู พอมีโจทย์แบบนี้อยู่ในมือ เวลาเลือกคอร์สถัดไปก็ง่ายขึ้นเยอะ
