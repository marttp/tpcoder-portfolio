I’m happy that models are getting better and agents can do more with them. I can hand an agent a task that spans a few files and come back to a diff with tests. On a good day, I spend less time setting things up and more time thinking about what the product should do. I like working this way.

The moment I think about is when something feels off. The agent can explain the code, write a test for it, and tell me everything passes. If I still feel unsure, do I know where to look, or will I just ask the same agent whether it’s sure?

## What does “canceled this month” mean?

Say I ask an agent to add a count of subscriptions canceled this month to a dashboard. It finds the date a customer clicked Cancel, groups the rows by month, and adds a test. The query is short. The chart looks fine.

Then I look at one customer. They clicked Cancel on September 28 and could still use the product through October 12. Which month should they appear in? September makes sense if the team wants to see when customers decided to leave. October makes sense if the team wants to see when those customers lost access. A test can pass for either definition.

![An engineer studies a flow that splits into two paths](/assets/images/blogs/when-your-ai-agent-gets-confused/trace.webp)

If the team wants to know when customers lost access, the chart based on cancel clicks puts this customer in the wrong month. I could ask the agent to review the whole diff again and get a careful explanation of why the query matches its test. What would get me unstuck is finding out what the team plans to do with that number. Once I know that, I can give the agent the September–October case and review the result against a number I can work out myself.

## What I still need to understand

I don’t need to memorize every table or write the query from scratch. I’d happily ask the agent to trace where each date comes from and help me check a few rows. I want to understand enough to notice when an assumption changes the answer. If someone from the team asks why a customer shows up in October, I should be able to explain it in a sentence.

![An engineer makes the final call at his desk](/assets/images/blogs/when-your-ai-agent-gets-confused/decision.webp)

Better models make it easier for me to hand off more of the work. I’m glad they do. **Once I choose to ship what the agent produced, it’s my work.** If the number is wrong, someone will come to me to ask what happened. I want to be able to open the dashboard with them, pick a row, and figure it out together.
